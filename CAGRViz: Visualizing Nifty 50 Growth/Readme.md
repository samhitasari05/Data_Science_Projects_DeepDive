# 📈 Nifty 50 CAGR Analyzer

This project calculates and visualizes the Compound Annual Growth Rate (CAGR) of the Nifty 50 index using Python and yfinance.

## 📊 Tools Used
- Python
- pandas
- yfinance
- matplotlib

## 🔧 Key Features
- Downloads real-time Nifty 50 data
- Calculates CAGR over any time period
- Visualizes indexed growth over time
